ชื่อโครงงาน: DC Circuit Calculator
โครงงานนี้เป็นการพัฒนาโปรแกรมเพื่อคำนวณหาค่ากระแสไฟฟ้าและกำลังไฟฟ้าที่เกิดขึ้นในวงจรตัวต้านทานได้อย่างรวดเร็วและแม่นยำ โดยมีเป้าหมายเพื่อช่วยลดข้อผิดพลาดในการคำนวณด้วยมือและเพิ่มประสิทธิภาพในการวิเคราะห์หรือออกแบบวงจรไฟฟ้าพื้นฐาน

## วิธีใช้งาน

รันโปรแกรมด้วยคำสั่ง:

```bash
python electrical.py
```

กรอกแรงดันไฟฟ้าเป็นโวลต์และค่าความต้านทานเป็นโอห์ม โปรแกรมจะแสดงค่ากระแสเป็นแอมแปร์และกำลังไฟฟ้าเป็นวัตต์ โดยค่าความต้านทานต้องมากกว่าศูนย์
